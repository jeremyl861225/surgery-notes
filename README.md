# 外科手術筆記

台大一般外科：哪位主治開哪台刀，擺位、打洞、器械、步驟怎麼做。

**線上版**：<https://jeremyl861225.github.io/surgery-notes/>

## 這是什麼

一個離線也能用的網頁（PWA），把住院醫師共享備忘錄「擺位共筆」整理成可查詢的形式。

查詢方式是「造句」：**〔哪位醫師〕的〔哪台刀〕**。兩個空格哪一個先填都可以——
先選醫師看他開的刀，或先選刀看誰在開、順便並排比較每個人的差異。

目前收錄 **20 位主治、33 種術式、37 則醫師筆記、4 則術式通則**。

## 一則筆記的欄位

擺位 · 切口與打洞 · 器械偏好 · 重要步驟 · 吻合方式 · 引流放置 · **傷口關法** · 傷口包紮 · 健保申報碼 · 備註

共筆原本只寫四段（擺位、Energy device、劃刀打洞、重要步驟），其餘欄位是留給之後補的，
沒寫的欄位會標成「共筆沒寫」而不是留白。

## 兩層通則

- **術式通則**：這台刀不分醫師都一樣的事（例如 LC 的 ICG 怎麼打）。來自共筆裡沒掛醫師名的那幾則。
- **醫師通則**：這位醫師開什麼刀都一樣的習慣。做法是把同一位醫師多則筆記中**逐字重複、
  且出現在超過半數筆記**的行抽出來，不做任何推論，並標明「見於 n/m 則」讓你自己判斷。
  **該醫師至少要有 3 則筆記**才做通則——兩則就宣稱「他開什麼刀都這樣」太滿，
  「見於 2/2」看起來像規則，其實只是兩個資料點。

## 新增草稿

每一頁都有「＋ 新增草稿」，可以打字也可以**附照片**。寫完馬上顯示，也存進雲端供之後整理成正式筆記。

表單最上面有一格**醫師通則**——寫「這位醫師不分哪台刀都一樣」的習慣。
寫在那裡的內容會出現在這位醫師的每一台刀上，不綁特定術式（術式那格可以不填）。

裝成 App 之後，主畫面**下拉可以更新**：補傳自己排隊中的草稿、重新去雲端拉別人的新草稿，
並順便檢查有沒有新版。

照片在瀏覽器裡就會先縮到最長邊 1600 px、轉成 WebP，這一步順便把 EXIF 洗掉
（GPS 座標與拍攝時間都在裡面）。要附照片一定要先勾「沒有病人的臉或身體」那個確認框。
寫入完全開放，不用登入。刪除鍵只會出現在寫的人自己的裝置上（每則草稿有一把只存在本機的
`del_token`）。雲端設定見 [SETUP.md](SETUP.md)；沒設定的話草稿只存在你這台裝置。

## 病人照片沒有放上來

共筆的附件裡有 27 張刀房實拍照片，其中有可辨識的病人影像（臉、會陰、乳房）。
這些**沒有**放進這個公開 repo，原處改顯示一行說明，要看請直接開備忘錄。
手繪的擺位圖與打洞圖 51 張全部收錄。

## 這不是什麼

不是診療指引，也不是台大醫院的正式文件。記的是各位主治醫師的個人偏好。
臨床決策請依當台刀的實際情況與主治醫師指示。

## 資料怎麼來的

原始資料在 iPhone 的共享備忘錄裡。抽取與建置腳本在
`workspace/work/surgery-notes/`（不在本 repo）：`parse.py` 剖標題與段落，
`build.py` 產生 `js/data.js`、壓縮手繪圖、濾掉病人照片。
